# Routes

This directory contains route components used by React Router.
Each file exports a page component that is imported in `src/App.tsx`.

## Conventions

| File                          | URL                        |
| ----------------------------- | -------------------------- |
| `index.tsx`                   | `/`                        |
| `about.tsx`                   | `/about`                   |
| `services.tsx`                | `/services`                |
| `projects.tsx`                | `/projects`                |
| `government-capabilities.tsx` | `/government-capabilities` |
| `certifications.tsx`          | `/certifications`          |
| `clients.tsx`                 | `/clients`                 |
| `contact.tsx`                 | `/contact`                 |
